# Product Roadmap

## Phase 1: Build and Deploy MVP

Build a working single-page demo of a two-tier RBAC system with:

- Convex schema for resources, roles, permissions, and users with seed data
- Permission evaluation engine (server + client) with composable multi-role support
- Convex queries and mutations for CRUD on roles, permissions, and user-role assignments
- Resource dashboard with authorized/unauthorized card states
- Role management UI with resource x action checkbox grid
- User role assignment UI with simulated user switching
- Deploy to Vercel and link in follow-up email

No post-launch roadmap. This is a one-time POC artifact for a job application.
