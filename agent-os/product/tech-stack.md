# Tech Stack

## Framework & Runtime

- **Application Framework:** TanStack Start (via create-z3-app)
- **Language/Runtime:** TypeScript / Node.js
- **Package Manager:** pnpm

## Frontend

- **JavaScript Framework:** React (via TanStack Start)
- **Routing:** TanStack Router
- **CSS Framework:** Tailwind CSS
- **UI Components:** shadcn/ui

## Backend & Database

- **Backend/Database:** Convex (reactive backend-as-a-service)
- **ORM/Query Builder:** Convex schema + query/mutation functions

## Deployment

- **Hosting:** Vercel

## Authentication

- None (simulated user switching via UI dropdown -- real auth is out of scope for this POC)
